# Mkulimer Ticketing API

A learning project for an ISP customer support ticketing system.

## Purpose

Build an API where customers can submit support tickets and technicians can
manage assignments and status updates.

## Planned features

- Create and track support tickets
- Assign tickets to technicians
- Notify customers about ticket updates
- Keep each ISP tenant's data separate
- Connect to billing systems through an API

## Technology

- Node.js
- TypeScript
- Node's built-in HTTP module
- PostgreSQL
- Postman for manual API requests
